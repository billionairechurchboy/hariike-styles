## 🌐 Deploy to Production

### Option 1: Netlify (Recommended)
1. Run: `npm run build`
2. Go to [netlify.com](https://netlify.com)
3. Drag `build` folder
4. Done! Free hosting + free HTTPS

### Option 2: Vercel
1. Run: `npm run build`
2. Go to [vercel.com](https://vercel.com)
3. Upload `build` folder
4. Done! Auto-deploys on updates

### Option 3: Your Server
1. Run: `npm run build`
2. Upload `build` folder to your server
3. Configure server for SPA routing

